Создание админ панели для управления заказами и пользователями для бильярда
1. Стэк технологий:
   - Backend:
    - Node.js с использованием Nest.js,
    - микросервисы с использованием Kafka,
    - авторизация и аутентификация по номеру телефона, почте или Google
    - обработка платежей через Stripe
    - MCP с PDP,
    - AI для анализа данных и прогнозирования спроса на столы.
    - Redis для кэширования и хранения сессий,
    - PostgreSQL для хранения данных,
    - Docker для управления контейнерами,
    - Docker Compose для управления сервисами,
    - Git для управления версиями,
    - CI/CD с использованием GitHub Actions,
    - Swagger для документации API.
    - AWS для хостинга и хранения картинок и файлов.
    - FSD архитектура
    - WebSocket для реального времени (например, уведомления о новых заказах)

   - Frontend:
    - Vue.js с использованием Nuxt.js,
    - Tailwind CSS для стилизации,
    - Pinia для управления состоянием,
    - Vite для сборки проекта,
    - Axios для работы с API,
    - WebSocket для реального времени (например, уведомления о новых заказах),
    - WebGL/Tree.js для визуализации бильярдного стола.
    - TanStack Query для работы с REST API.
    - FSD архитектура
    - AI для анализа данных и прогнозирования спроса на столы.
    - Google Maps API для отображения местоположения бильярдных клубов на карте.
    - Stripe для обработки платежей на фронтенде.
    - Shadcn ui для создания пользовательского интерфейса.
    - Tauri для создания кроссплатформенного десктопного приложения.

2. Функциональные требования:
   - Регистрация и авторизация пользователей.
   - Создание и управление заказами.
   - Просмотр статистики заказов.
   - Просмотр списка бильярдных клубов.
   - Управление пользователями (создание, редактирование, удаление).
   - Управление бильярдными клубами (создание, редактирование, удаление).
    - Управление столами (создание, редактирование, удаление).
    - Управление расписанием работы бильярдных клубов.
    - Управление платежами и финансовой отчетностью.
    - Уведомления о новых заказах и изменениях в заказах.
    - Анализ данных и прогнозирование спроса на столы.
    - Отображение местоположения бильярдных клубов на карте.
    - Обработка платежей через Stripe.
    - Интеграция с Google Maps API.
    - Интеграция с Stripe.
    - Интеграция с Shadcn ui.
    - Интеграция с Tauri.

3. Нефункциональные требования:
   - Высокая производительность и масштабируемость.
   - Безопасность данных пользователей.
   - Удобный и интуитивно понятный интерфейс.
   - Легкость в поддержке и расширении функционала.
   - Использование современных технологий и подходов в разработке.
   - Возможность интеграции с другими сервисами и платформами.
