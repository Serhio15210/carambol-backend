# Carambol Backend — учебный проект

Бэкенд админ-панели для бильярдных клубов: пользователи, клубы, столы, бронирования,
оплата, уведомления. Проект учебный: цель — научиться строить большие масштабируемые
бэкенды. Методика обучения (учитель/ученик, уроки, правило перехода) описана в
глобальном `~/.claude/CLAUDE.md` и обязательна в этом проекте.

Исходный план технологий и функционала: `plan.txt`.
Старая версия кода (микросервисы, Kafka, Stripe, заказы, столы, тарифы) сохранена
в git-коммите `8dd4aec`. К ней можно обращаться как к справке в соответствующих уроках.

## Стек и архитектура

- Nest.js 11 + TypeScript, PostgreSQL 16, TypeORM, Docker Compose.
- Архитектура: **модульный монолит** (FSD из plan.txt заменён: это методология
  для фронтенда). Каждая фича — модуль в `src/modules/<name>/`
  (module, controller, service, `entities/`, `dto/`, `types/`).
- Модули общаются только через экспортированные сервисы (`exports: [XService]`),
  а не через чужие репозитории или таблицы.
- Импорты внутри модуля относительные (`./users.service`), между модулями — через
  алиас `@/modules/...`.
- Общий код без привязки к фиче лежит в `src/common/`, настройки в `src/config/`,
  подключение к БД в `src/database/`.

## Команды

- `docker compose up -d` — поднять PostgreSQL
- `npm run start:dev` — запустить API в режиме разработки (http://localhost:3000/api)
- `npm run build` — сборка
- `npm run lint` — линтер (ESLint + Prettier)
- `npm test` / `npm run test:e2e` — тесты

## Договорённости об обучении (уточнения ученика)

- Конфигурационные файлы (YAML для CI, Dockerfile, docker-compose, настройки
  инструментов) пишет учитель целиком, как это принято на практике: из шаблонов
  и с помощью AI. Ученик не обязан писать их с нуля, но учитель обязан разобрать
  файл построчно, а после этого проверить понимание вопросами.
- `TODO(human)` оставляем для логики приложения: бизнес-правила, проверки,
  алгоритмы, работа с данными.

- Язык репозитория: всё, что попадает на GitHub (issues, PR, коммиты, новые файлы,
  комментарии в коде), пишется на английском. Объяснения для ученика даются в чате
  на русском. Существующие русские комментарии и файлы (около 40, список через
  `git grep -l -E "[а-яА-ЯёЁ]"`) решено перевести позже одним отдельным PR после
  урока 3; до этого новый код пишем сразу на английском.

- Коммиты: сообщение строго в одну строку (Conventional Commits), без тела и без
  трейлера Co-Authored-By. Ключевые слова закрытия issue (`closes #N`) пишутся
  в той же строке.
